7.1 Was ist CSS?

CSS heißt Cascading Style Sheets. Damit legst du fest, wie HTML-Elemente aussehen: Farben, Schriften, Abstände, Größen, Anordnung und Animationen. Der große Vorteil: Eine CSS-Datei kann das Aussehen von beliebig vielen Seiten steuern. Alle Seiten dieser Website nutzen dieselbe style.css.

7.2 CSS einbinden: drei Wege

  1. Extern (empfohlen): eine eigene Datei, eingebunden im head mit <link rel="stylesheet" href="style.css">
  2. Intern: ein <style>-Block im HTML (so wie in den Beispielen auf dieser Seite)
  3. Inline: direkt am Element mit style="..."

💡 Gibt es mehrere Regeln für dasselbe Element, gewinnt inline vor intern/extern. Deshalb ist inline schwer zu überschreiben und sollte selten benutzt werden.

7.3 Syntax

Eine CSS-Regel besteht aus einem Selektor und einem Deklarationsblock in geschweiften Klammern. Jede Deklaration ist eigenschaft: wert; mit Semikolon am Ende.

h2 {                    /* Selektor: alle h2-Elemente */
  color: navy;          /* Eigenschaft: Wert; */
  font-size: 1.5rem;    /* jede Zeile endet mit ; */
}

/* So schreibt man in CSS einen Kommentar (auch über mehrere Zeilen) */

7.6 Farben

Farben kann man auf mehrere Arten angeben:

  • Namen: red, tomato, royalblue … (über 140 Stück)
  • Hex: #ff6347 – Rot, Grün, Blau je zweistellig von 00 bis ff. Kurz: #f00
  • RGB: rgb(255 99 71) – jeweils 0 bis 255
  • Transparenz: rgb(255 99 71 / 50%) oder Hex mit 8 Stellen #ff634780
  • HSL: hsl(9 100% 64%) – Farbton (0–360°), Sättigung, Helligkeit. Gut zum Abwandeln!

7.7 Hintergründe

  • background-color – Hintergrundfarbe
  • background-image – Bild url(...) oder Verlauf linear-gradient(...)
  • background-size – cover (füllt alles), contain (ganz sichtbar)
  • background-repeat – wiederholen oder nicht (no-repeat)
  • background-position – wo das Bild sitzt, z. B. center

7.9 Kaskade, Spezifität und Vererbung

Was passiert, wenn mehrere Regeln dasselbe Element treffen? Der Browser entscheidet so:

  1. Wichtigkeit: !important gewinnt (nur im Notfall benutzen!).
  2. Spezifität: genauere Selektoren gewinnen. Reihenfolge: inline-style > ID > Klasse/Attribut/Pseudo-Klasse > Element.
  3. Reihenfolge: bei Gleichstand gewinnt die Regel, die später steht.

Vererbung: Manche Eigenschaften (z. B. color, font-family) erben Kinder automatisch vom Eltern-Element, andere (z. B. border, padding) nicht.

7.10 CSS-Variablen

Variablen (eigentlich „Custom Properties“) beginnen mit -- und werden mit var(--name) gelesen. Meist definiert man sie in :root, dann gelten sie überall. Deine style.css macht das schon für die Farben, und der Dunkelmodus ändert einfach nur die Variablen.


✍️ Übungen

  1. Erstelle uebung.css und binde sie in deine Übungsseite ein. Färbe alle h2 in deiner Lieblingsfarbe (als hsl).
  2. Gib einem Absatz eine Klasse hinweis mit hellgelbem Hintergrund und einem anderen eine ID mit fetter Schrift.
  3. Mach den body-Hintergrund zu einem Verlauf von oben (hell) nach unten (etwas dunkler).
  4. Schreib zwei widersprüchliche Regeln und sag vorher, welche gewinnt. Prüfe es mit F12.
  5. Ändere in style.css die Variable --akzent und schau, wie sich alle Seiten ändern.
