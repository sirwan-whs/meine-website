3.1 Was ist HTML?

HTML steht für HyperText Markup Language. Es ist keine Programmiersprache, sondern eine Auszeichnungssprache: Du sagst dem Browser mit sogenannten Tags, was ein Stück Text ist, zum Beispiel eine Überschrift, ein Absatz oder ein Link.

  • HTML = Struktur und Inhalt (das Skelett)
  • CSS = Aussehen (Kleidung und Farben)
  • JavaScript = Verhalten (die Muskeln)

💡 Tipp: Rechtsklick auf eine Webseite → Seitenquelltext anzeigen (oder Strg + U) zeigt dir das HTML jeder Website.

3.2 Aufbau einer HTML-Seite

Jede HTML-Seite hat dasselbe Grundgerüst. In VS Code bekommst du es, wenn du in einer leeren .html-Datei ! tippst und Enter drückst.

<!DOCTYPE html>              <!-- sagt: das ist modernes HTML5 -->
<html lang="de">             <!-- Wurzel-Element, Sprache Deutsch -->
  <head>                     <!-- unsichtbare Infos für den Browser -->
    <meta charset="UTF-8">   <!-- Umlaute richtig anzeigen -->
    <title>Mein Titel</title> <!-- Text im Browser-Tab -->
  </head>
  <body>                     <!-- alles Sichtbare kommt hier rein -->
    <h1>Hallo Welt</h1>
  </body>
</html>

💡 Die Zeichen &lt; und &gt; im Quelltext dieser Seite sind „Entities“ für < und >. Mehr dazu auf Seite 6.

3.3 Elemente

Ein Element besteht meist aus einem Start-Tag, dem Inhalt und einem End-Tag mit Schrägstrich: <p>Inhalt</p>.

Manche Elemente sind leer (void elements) und haben kein End-Tag, zum Beispiel <br> (Zeilenumbruch), <hr> (Trennlinie) und <img> (Bild).

Elemente können verschachtelt werden. Wichtig: Was zuletzt geöffnet wurde, wird zuerst geschlossen.

3.4 Attribute

Attribute geben einem Element zusätzliche Infos. Sie stehen immer im Start-Tag, in der Form name="wert".

  • href – Ziel eines Links
  • src und alt – Quelle und Ersatztext eines Bildes
  • id – eindeutiger Name (nur einmal pro Seite!)
  • class – Gruppenname für CSS, darf mehrfach vorkommen
  • title – Tooltip, erscheint beim Drüberfahren mit der Maus
  • lang – Sprache des Inhalts
  • style – CSS direkt am Element

3.6 Absätze und Zeilenumbrüche

<p> ist ein Absatz. Der Browser ignoriert mehrere Leerzeichen und Zeilenumbrüche im Quelltext und macht daraus ein einziges Leerzeichen. Für einen Zeilenumbruch brauchst du <br>. Willst du den Text genau so anzeigen, wie er getippt ist, nimm <pre>.

Dieser Text hat viele Leerzeichen und Umbrüche im Quelltext, wird aber in einer Zeile angezeigt.

3.7 Text formatieren

Für Text gibt es viele kleine Elemente. Manche haben eine Bedeutung (semantisch), andere ändern nur das Aussehen. Bevorzuge die semantischen: <strong> statt <b> und <em> statt <i>.

b – fett, ohne besondere Bedeutung

strong – wichtig (wird fett dargestellt)

i – kursiv, z. B. für Fachbegriffe oder Gedanken

em – betont (wird kursiv), Screenreader betonen es

mark – markiert wie mit Textmarker

small – Kleingedrucktes

del – gelöschter Text, ins – eingefügter Text

H2O – sub ist tiefgestellt

E = mc2 – sup ist hochgestellt

code – Programmcode, Strg + C – Tastatureingabe

3.9 Kommentare

Kommentare beginnen mit <!-- und enden mit -->. Der Browser zeigt sie nicht an. Nutze sie für Notizen oder um Code vorübergehend „auszuschalten“. In VS Code: Zeile markieren und Strg + #.

Dieser Absatz ist sichtbar.

3.10 Das style-Attribut

Mit style kannst du CSS direkt an ein Element schreiben (inline). Das ist praktisch zum Ausprobieren. Für echte Seiten ist eine CSS-Datei besser, weil man dort alles an einer Stelle ändert. CSS lernst du ab Seite 7.
