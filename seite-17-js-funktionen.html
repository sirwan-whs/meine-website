17.1 Warum Funktionen?

  • Nicht wiederholen (DRY: „Don’t Repeat Yourself“): Code einmal schreiben, oft benutzen
  • Übersicht: Ein guter Name erklärt, was der Code tut
  • Einfacher ändern: Fehler nur an einer Stelle beheben

Du kennst schon viele eingebaute Funktionen: console.log(), Math.round(), alert(). Jetzt schreibst du eigene.

17.2 Funktion schreiben und aufrufen

Eine Funktionsdeklaration beginnt mit function, dann Name, runde Klammern und der Code in geschweiften Klammern. Sie läuft erst, wenn man sie aufruft: name().

💡 Gute Funktionsnamen beginnen mit einem Verb: berechneSumme, zeigeFehler, istGueltig.

17.3 Parameter und Argumente

Parameter sind Platzhalter in der Definition. Argumente sind die echten Werte beim Aufruf. Fehlt ein Argument, ist der Parameter undefined, außer du gibst einen Standardwert mit = an.

17.4 return: Ergebnis zurückgeben

Mit return gibt eine Funktion einen Wert zurück, mit dem man weiterarbeiten kann. return beendet die Funktion sofort, Code danach läuft nicht mehr. Ohne return gibt eine Funktion undefined zurück.

17.5 Funktionsausdrücke

Eine Funktion kann auch in einer Variablen gespeichert werden. Unterschied zur Deklaration: Deklarationen kann man schon vor ihrer Zeile aufrufen (das nennt man Hoisting), Ausdrücke erst danach.

17.6 Pfeilfunktionen

Die moderne Kurzschreibweise mit =>. Sehr beliebt, vor allem für kleine Funktionen:

  • Mehrere Parameter in Klammern: (a, b) => a + b
  • Ein Parameter, Klammern optional: x => x * 2
  • Kein Parameter: () => console.log("Hi")
  • Nur ein Ausdruck: Ergebnis wird automatisch zurückgegeben, ohne return und ohne { }
  • Mehrere Zeilen: dann { } und return wie gewohnt

17.7 Gültigkeitsbereich (Scope)

Wo ist eine Variable sichtbar?

  • Global: außerhalb jeder Funktion, überall sichtbar
  • Funktion: innerhalb einer Funktion, nur dort sichtbar
  • Block: let und const in { } (z. B. in if oder for) gibt es nur in diesem Block

Von innen sieht man nach außen, aber nicht von außen nach innen.

💡 Benutze so wenige globale Variablen wie möglich. Lokale Variablen können sich nicht gegenseitig in die Quere kommen.

17.8 Funktionen als Werte: Callbacks

In JavaScript sind Funktionen ganz normale Werte. Man kann sie an andere Funktionen übergeben. So eine übergebene Funktion heißt Callback („Rückruf“): Sie wird später aufgerufen. Das kennst du schon von addEventListener("click", function () { … }).

⚠️ Häufiger Fehler: addEventListener("click", beiKlick()) mit Klammern ruft die Funktion sofort auf. Richtig ist beiKlick ohne Klammern.
