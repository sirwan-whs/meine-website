14.1 Was ist JavaScript?

JavaScript (kurz JS) ist eine echte Programmiersprache. Sie läuft direkt im Browser und macht Webseiten interaktiv: auf Klicks reagieren, Inhalte ändern, rechnen, Daten laden. Mit Node.js läuft JavaScript auch auf Servern. Trotz des Namens hat es mit Java nichts zu tun.

💡 Die beste Spielwiese: F12 drücken, Reiter Konsole öffnen und dort direkt JavaScript eintippen, z. B. 2 + 3 und Enter.

14.2 JavaScript einbinden

  1. Extern (empfohlen): <script src="skript.js"></script>, am besten am Ende des body oder im head mit defer
  2. Intern: Code direkt zwischen <script> und </script> (so wie in den Beispielen hier)
<head>
  <!-- defer: erst ausführen, wenn das HTML fertig geladen ist -->
  <script src="skript.js" defer></script>
</head>

💡 Steht ein Skript ohne defer im head, ist das HTML darunter noch nicht geladen. Dann findet document.getElementById nichts. Deshalb stehen deine Skripte am Ende des body.

14.3 Ausgabe: console.log und Co.

  • console.log(...) – Ausgabe in der Konsole, das wichtigste Werkzeug zum Testen
  • console.warn(...) / console.error(...) – Warnung / Fehler (gelb / rot)
  • element.textContent = ... – Text in die Seite schreiben
  • alert(...) – Meldungsfenster (siehe 14.12)

Dieser Text wird beim Klick ersetzt.

14.4 Syntax und Kommentare

  • Eine Anweisung endet mit einem Semikolon ; (es ist oft optional, aber schreib es immer).
  • JavaScript unterscheidet Groß- und Kleinschreibung: name und Name sind verschieden.
  • // … ist ein einzeiliger Kommentar, /* … */ ein mehrzeiliger.
  • Code-Blöcke stehen in geschweiften Klammern { }.
  • Namen schreibt man in camelCase: anzahlKlicks, meinErsterWert.

14.5 Variablen: let, const, var

Eine Variable ist eine beschriftete Schachtel für einen Wert.

SchlüsselwortNeu zuweisen?Benutzen?
constnein✅ Standard. Immer zuerst const nehmen.
letja✅ wenn sich der Wert ändern muss (Zähler …)
varja❌ alte Schreibweise mit Tücken, nicht mehr benutzen

Regeln für Namen: Buchstaben, Ziffern, _ und $; nicht mit einer Ziffer anfangen; keine reservierten Wörter wie let oder if. Umlaute gehen, sind aber unüblich.

14.11 Typumwandlung

Eingaben aus Formularen sind immer Text. Zum Rechnen musst du sie in Zahlen umwandeln:

  • Number("42") → 42 (bei Unsinn: NaN = „Not a Number“)
  • parseInt("42px") → 42, parseFloat("3.5kg") → 3.5
  • String(42) oder (42).toString() → "42"
  • Boolean(wert) → true oder false

14.12 alert, confirm, prompt

Drei eingebaute Fenster. Sie blockieren die Seite, deshalb nutzt man sie heute nur zum schnellen Ausprobieren.

  • alert("Text") – zeigt eine Meldung
  • confirm("Frage?") – OK oder Abbrechen, ergibt true oder false
  • prompt("Frage?") – Eingabefeld, ergibt den Text (oder null bei Abbrechen)
