5.1 Das form-Element

<form> umschließt alle Eingabefelder. Zwei wichtige Attribute:

  • action – an welche Adresse die Daten geschickt werden (z. B. /anmelden)
  • method – wie: get hängt die Daten an die Adresse (?name=Sirwan), post schickt sie unsichtbar mit (für Passwörter!)

Jedes Feld braucht ein name-Attribut, sonst wird es nicht mitgeschickt.

💡 Nach dem Absenden steht in der Adresszeile z. B. ?suchbegriff=html. So sieht method="get" aus.

5.3 Input-Typen

Das Attribut type bestimmt, wie das Feld aussieht und was man eingeben kann. Auf dem Handy passt sich sogar die Tastatur an.

5.4 Checkbox, Radio, Auswahl

  • Checkbox: beliebig viele ankreuzen
  • Radio: genau eine Option. Alle Radios einer Gruppe brauchen denselben name.
  • select: Aufklappliste, mit multiple auch Mehrfachauswahl
  • datalist: Vorschläge für ein Textfeld

5.7 Eingaben prüfen (Validierung)

Der Browser kann Eingaben selbst prüfen, ganz ohne JavaScript. Versuch, das Formular falsch abzuschicken:

  • required – Pflichtfeld
  • minlength / maxlength – Mindest- und Höchstlänge von Text
  • min / max / step – für Zahlen und Datum
  • pattern – ein Muster (regulärer Ausdruck)
  • type="email" prüft automatisch auf ein @

💡 Wichtig für später: Prüfungen im Browser kann man umgehen. Ein echter Server muss die Daten immer noch einmal selbst prüfen.
