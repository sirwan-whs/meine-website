18.1 Arrays erstellen und lesen

Ein Array steht in eckigen Klammern [ ], die Werte sind durch Kommas getrennt. Jeder Wert hat einen Index ab 0. Ein Array darf verschiedene Typen enthalten, auch andere Arrays.

💡 const verhindert nur, dass die Variable ein anderes Array bekommt. Den Inhalt darf man ändern.

18.3 splice und slice

  • slice(start, ende) – gibt eine Kopie eines Ausschnitts zurück, das Original bleibt
  • splice(start, anzahl, ...neu) – ändert das Original: entfernt und/oder fügt ein

18.6 map und filter

Die beiden wichtigsten Methoden. Beide geben ein neues Array zurück und ändern das Original nicht.

  • map(fn) – verwandelt jedes Element. Gleich viele Elemente rein wie raus.
  • filter(fn) – siebt: behält nur Elemente, für die fn true ergibt.

18.7 reduce

reduce fasst ein ganzes Array zu einem Wert zusammen (z. B. eine Summe). Der Callback bekommt den bisherigen Zwischenstand (Akkumulator) und das aktuelle Element. Der zweite Parameter ist der Startwert.

18.8 some und every

  • some(fn) – true, wenn mindestens ein Element passt
  • every(fn) – true, wenn alle Elemente passen

18.9 Sortieren und umdrehen

sort() sortiert standardmäßig als Text, auch Zahlen! Für Zahlen gibst du eine Vergleichsfunktion mit: (a, b) => a - b (aufsteigend). sort und reverse ändern das Original. Die neuen Varianten toSorted() und toReversed() geben eine Kopie zurück.

18.10 Spread, Destructuring und mehr

  • Spread ... – „packt aus“: Arrays kopieren und verbinden
  • Destructuring – Werte direkt in Variablen auspacken
  • Array.from(), flat(), fill(), new Set() für Duplikate
