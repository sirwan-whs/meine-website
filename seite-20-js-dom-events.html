20.1 Was ist der DOM?

Wenn der Browser HTML lädt, baut er daraus einen Baum. Jedes Element ist ein Knoten (Node) mit Eltern, Kindern und Geschwistern. Ganz oben steht document. JavaScript kann jeden Knoten finden, lesen, ändern, löschen und neue hinzufügen. 

document
└── html
    ├── head
    │   └── title
    └── body
        ├── header
        │   └── h1
        └── main
            └── section
                ├── h2
                └── p

💡 F12 → Reiter „Elemente“ zeigt dir genau diesen Baum, und zwar den aktuellen Stand, auch nach Änderungen durch JavaScript.

20.3 Inhalt ändern

  • textContent – nur Text. Sicher, weil HTML nicht ausgeführt wird. Erste Wahl!
  • innerHTML – liest/schreibt HTML. ⚠️ Nie mit Eingaben von Nutzern füllen, sonst kann fremder Code ausgeführt werden (XSS).
  • value – Inhalt von Eingabefeldern

20.4 Attribute und data-*

  • getAttribute("name"), setAttribute("name", "wert"), removeAttribute("name"), hasAttribute("name")
  • Viele Attribute direkt als Eigenschaft: img.src, a.href, input.disabled
  • Eigene Daten mit data-irgendwas="…", lesen mit element.dataset.irgendwas

20.5 Stil und Klassen ändern

  • element.style.backgroundColor = "red" – einzelne Stile (CSS-Namen in camelCase)
  • classList.add("x"), remove("x"), toggle("x"), contains("x") – besser: Aussehen im CSS festlegen und nur Klassen wechseln

20.8 Events: addEventListener

Ein Event (Ereignis) ist etwas, das passiert: ein Klick, ein Tastendruck, das Absenden eines Formulars. Mit element.addEventListener("typ", funktion) reagierst du darauf. removeEventListener entfernt die Reaktion wieder.

EventWann?
click, dblclickKlick, Doppelklick
mouseenter, mouseleaveMaus kommt / geht
keydown, keyupTaste gedrückt / losgelassen
inputbei jeder Änderung in einem Feld
changewenn ein Feld fertig geändert ist (z. B. select, checkbox)
submitFormular wird abgeschickt
focus, blurFeld bekommt / verliert den Fokus
DOMContentLoaded, loadHTML fertig / alles inklusive Bilder fertig
scroll, resizeSeite scrollt / Fenstergröße ändert sich
Klick, Doppelklick, Maus rein und raus

20.9 Das Event-Objekt

Die Funktion bekommt automatisch ein Event-Objekt mit allen Infos:

  • event.target – das Element, auf dem es passiert ist
  • event.type – der Typ, z. B. "click"
  • event.clientX / clientY – Mausposition
  • event.key – welche Taste
  • event.preventDefault() – Standardverhalten verhindern (Link folgen, Formular absenden)

20.11 Event-Delegation und Bubbling

Events „blubbern“ nach oben (Bubbling): Ein Klick auf ein li ist auch ein Klick auf das ul, das section und so weiter. Das nutzt die Delegation: Statt jedem Eintrag einen Listener zu geben, bekommt nur das Eltern-Element einen. Vorteil: Funktioniert auch für Einträge, die erst später hinzukommen. event.stopPropagation() stoppt das Blubbern.
