13.1 Was ist Responsive Design?

Responsive heißt: Die Seite passt sich an jede Bildschirmgröße an, vom Handy bis zum großen Monitor. Die Zutaten kennst du schon:

  1. Der Viewport-Meta-Tag im head (sonst zeigt das Handy eine verkleinerte PC-Seite)
  2. Flexible Breiten (%, fr, max-width) statt fester Pixel
  3. Flexbox mit wrap und Grid mit auto-fill
  4. Media Queries für alles, was sich wirklich ändern muss

💡 Testen: F12 drücken, dann das Handy-Symbol oben links in den Entwicklertools (Strg + Umschalt + M). Dort kannst du verschiedene Geräte auswählen.

13.2 Media Queries

Eine Media Query ist eine Bedingung. Die Regeln darin gelten nur, wenn sie zutrifft:

@media (max-width: 600px) {     /* bis 600px Breite */
  .menue { flex-direction: column; }
}

@media (min-width: 900px) {     /* ab 900px Breite */
  .spalten { grid-template-columns: 1fr 1fr 1fr; }
}

@media (min-width: 600px) and (max-width: 899px) { … }   /* dazwischen */
@media (orientation: landscape) { … }                    /* Querformat */
@media print { … }                                       /* beim Drucken */

13.3 Mobile First

Mobile First heißt: Erst schreibst du das CSS für das Handy (ohne Media Query), dann erweiterst du es mit min-width für größere Bildschirme. Das Beispiel oben arbeitet genau so. Vorteil: Das Handy lädt nur einfache Regeln, und die einspaltige Ansicht ist sowieso der einfachste Fall.

13.4 Flexible Bilder und Schrift

  • img { max-width: 100%; height: auto; } – Bilder werden nie breiter als ihr Platz (steht schon in deiner style.css)
  • object-fit: cover – Bild füllt einen festen Rahmen, ohne verzerrt zu werden
  • font-size: clamp(1rem, 2.5vw, 2rem) – Schrift wächst mit dem Fenster, aber in Grenzen

13.5 Nutzer-Vorlieben: Dunkelmodus und weniger Bewegung

Media Queries können auch Einstellungen des Betriebssystems abfragen:

/* Der Nutzer hat in Windows/macOS den dunklen Modus eingestellt */
@media (prefers-color-scheme: dark) {
  :root { --hintergrund: #12151f; --text: #e8eaf2; }
}

/* Der Nutzer möchte weniger Animationen (z. B. wegen Schwindel) */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}

💡 Deine Website hat einen eigenen Schalter (theme.js). Als Übung könntest du ihn so erweitern, dass beim allerersten Besuch die System-Einstellung übernommen wird: matchMedia("(prefers-color-scheme: dark)").matches.

13.6 Übergänge (transition)

Ohne transition springt eine Änderung (z. B. bei :hover) sofort. Mit transition wird sie weich animiert. Schreibweise: transition: eigenschaft dauer zeitkurve verzögerung;

  • Zeitkurven: ease (Standard), linear, ease-in, ease-out, ease-in-out
  • Mehrere: transition: background-color 0.3s, transform 0.5s;

13.7 Transformationen (transform)

Mit transform verschiebst, drehst, skalierst und neigst du ein Element, ohne dass sich das Layout drumherum verschiebt:

  • translate(x, y) – verschieben
  • rotate(45deg) – drehen
  • scale(1.5) – vergrößern / verkleinern
  • skew(10deg) – neigen
  • Mehrere: transform: rotate(10deg) scale(1.2);
  • transform-origin – um welchen Punkt gedreht wird

13.8 Animationen mit @keyframes

Eine Transition braucht einen Auslöser (z. B. hover). Eine Animation läuft von selbst. In @keyframes legst du fest, wie es zu bestimmten Zeitpunkten aussieht (from/to oder Prozente). Dann hängst du die Animation an ein Element:

EigenschaftBedeutung
animation-nameName der @keyframes
animation-durationDauer, z. B. 2s
animation-iteration-countWiederholungen, infinite = endlos
animation-directionalternate = hin und zurück
animation-timing-functionZeitkurve wie bei transition
animation-delayVerzögerung
animation-fill-modeforwards = am Ende stehen bleiben

✍️ Übungen

  1. Mach deine Übungsseite responsive: Navigation auf dem Handy untereinander, ab 600px nebeneinander.
  2. Gib allen Buttons einen weichen Übergang bei hover (Farbe und leichte Vergrößerung).
  3. Baue eine Animation, bei der ein Herz ❤️ pulsiert (scale von 1 auf 1.2 und zurück).
  4. Lass Karten beim Laden der Seite nacheinander hereinfliegen (Tipp: unterschiedliche animation-delay).
  5. Füge prefers-reduced-motion hinzu, damit deine Animationen bei Bedarf ausgeschaltet werden.
