15.1 Strings erstellen

Ein String ist Text. Er steht in Anführungszeichen: doppelt "…", einfach '…' oder in Backticks `…`. Sonderzeichen schreibst du mit einem Backslash \ (Escape):

  • \n – neue Zeile
  • \" bzw. \' – Anführungszeichen im Text
  • \\ – ein Backslash

15.2 Template Strings

Mit Backticks `…` kannst du Variablen und sogar Rechnungen direkt mit ${…} einsetzen, und der Text darf über mehrere Zeilen gehen. Viel lesbarer als +!

15.3 Länge und einzelne Zeichen

Die Position eines Zeichens heißt Index und beginnt bei 0!

💡 Strings sind unveränderlich. Methoden wie toUpperCase() ändern nie das Original, sondern geben einen neuen String zurück.

15.6 Zahlen

In JavaScript gibt es nur einen Zahlentyp number für ganze und Kommazahlen. Besondere Werte:

  • NaN – „Not a Number“, Ergebnis einer ungültigen Rechnung. Prüfen mit Number.isNaN(x)
  • Infinity – unendlich, z. B. bei 1 / 0
  • Number.isInteger(x) – ist es eine ganze Zahl?

15.7 Zahlen formatieren

  • zahl.toFixed(2) – auf 2 Nachkommastellen runden (ergibt einen String)
  • zahl.toLocaleString("de-DE") – deutsches Format mit Punkt und Komma
  • Intl.NumberFormat – z. B. als Währung

15.9 Zufallszahlen

Math.random() gibt eine Kommazahl zwischen 0 (inklusive) und 1 (exklusive). Für eine ganze Zahl von 1 bis 6:

Math.floor(Math.random() * 6) + 1
//         0 … 5.999   → 0 … 5  → 1 … 6

Viele String-Methoden auf einmal. Tipp etwas ein, die Prüfung läuft bei jeder Taste (Ereignis input).
