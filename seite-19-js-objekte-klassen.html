19.1 Objekte erstellen und lesen

Ein Objekt steht in geschweiften Klammern und besteht aus Schlüssel-Wert-Paaren (Eigenschaften): schluessel: wert, getrennt durch Kommas. Lesen mit Punkt objekt.name oder eckigen Klammern objekt["name"].

19.3 Methoden und this

Eine Funktion in einem Objekt heißt Methode. Mit this greift sie auf ihr eigenes Objekt zu.

💡 Pfeilfunktionen haben kein eigenes this. Für Methoden deshalb die normale Schreibweise nehmen.

19.4 Objekte durchlaufen

  • Object.keys(obj) – Array aller Schlüssel
  • Object.values(obj) – Array aller Werte
  • Object.entries(obj) – Array von [schluessel, wert]-Paaren

19.7 Kopie oder Referenz?

Zahlen und Strings werden beim Zuweisen kopiert. Objekte und Arrays nicht: Die Variable enthält nur einen Verweis (Referenz) auf dasselbe Objekt. Ändert man es über die eine Variable, sieht man es auch über die andere!

19.8 JSON

JSON (JavaScript Object Notation) ist ein Textformat, um Daten zu speichern und zwischen Programmen auszutauschen, z. B. mit einem Server. Es sieht aus wie ein JS-Objekt, aber: Schlüssel und Strings immer in doppelten Anführungszeichen, keine Funktionen, keine Kommentare, kein Komma am Ende.

  • JSON.stringify(objekt) – Objekt → JSON-Text
  • JSON.parse(text) – JSON-Text → Objekt

💡 So speichert deine To-do-Liste (Seite 1) ihre Aufgaben im localStorage: Der kann nur Text, deshalb JSON.

19.9 Klassen

Eine Klasse ist ein Bauplan für viele gleichartige Objekte. constructor läuft beim Erzeugen mit new und setzt die Startwerte. Klassennamen schreibt man groß. #name ist ein privates Feld, das man von außen nicht ändern kann. get macht eine berechnete Eigenschaft, static eine Methode der Klasse selbst.

19.10 Vererbung

Mit extends übernimmt eine Klasse alles von einer anderen und kann es erweitern. super(...) ruft den Konstruktor der Eltern-Klasse auf.

19.11 Praxis: Warenkorb

Eine Klasse verwaltet die Daten, eine Funktion zeigt sie an. Diese Trennung macht Programme übersichtlich.
