22.1 Fehlerarten

Wenn JavaScript etwas nicht ausführen kann, wirft es einen Fehler (Error). Ohne Behandlung bricht das Skript an dieser Stelle ab. Jeder Fehler hat einen name (die Art) und eine message (die Beschreibung).

NameWann?Beispiel
ReferenceErrorVariable gibt es nichtconsole.log(gibtsNicht)

RangeErrorZahl außerhalb des erlaubten Bereichs(5).toFixed(200)

22.2 try, catch und finally

  • try { … } – Code, bei dem etwas schiefgehen kann.
  • catch (fehler) { … } – läuft nur, wenn im try ein Fehler passiert. Das Skript läuft danach weiter.
  • finally { … } – läuft immer, z. B. zum Aufräumen.

💡 Fang Fehler nur dort ab, wo du sinnvoll reagieren kannst (Meldung zeigen, Standardwert nehmen). Ein leerer catch {} versteckt Fehler, und du suchst später stundenlang.

22.3 throw und eigene Fehler

Mit throw new Error("Text") wirfst du selbst einen Fehler, z. B. wenn eine Eingabe ungültig ist. Für eigene Fehlerarten erweitert man die Klasse Error (Klassen: Seite 19).

22.5 Date: Datum und Uhrzeit

Ein Date-Objekt ist ein Zeitpunkt. Erzeugen kann man es so:

  • new Date() – jetzt
  • new Date(2026, 11, 24) – 24. Dezember 2026 (Achtung: Monate zählen ab 0, also 11 = Dezember!)
  • new Date("2026-12-24T18:00") – aus einem Text im ISO-Format

22.10 Module: import und export

Wird ein Projekt groß, teilt man den Code in mehrere Dateien auf. Ein Modul gibt mit export frei, was andere benutzen dürfen, und holt sich mit import, was es braucht. Variablen eines Moduls sind nicht global, also gibt es keine Namenskonflikte mehr.

Datei mathe.js:

// Benannte Exporte: beliebig viele
export const PI = 3.14159;
export function kreisFlaeche(r) {
  return PI * r * r;
}

// Standard-Export: höchstens einer pro Datei
export default function begruesse(name) {
  return `Hallo ${name}!`;
}

Datei app.js:

// Benannte Exporte in geschweiften Klammern, Standard-Export ohne
import begruesse, { kreisFlaeche, PI } from "./mathe.js";

console.log(begruesse("Sirwan"));
console.log(kreisFlaeche(2).toFixed(2));

// await geht in Modulen auch ohne async-Funktion
const antwort = await fetch("daten/kurse.json");

Im HTML braucht das Skript type="module":

<script type="module" src="app.js"></script>
  • Module werden automatisch erst nach dem HTML ausgeführt (wie defer).
  • Wie fetch brauchen Module einen Server: Live Server oder GitHub Pages, nicht file://.
  • Der Pfad muss mit ./ oder ../ beginnen und die Endung .js haben.
